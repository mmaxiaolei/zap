# 总结 PR / 变更

<!-- drafted by create-skill from Skill 生成向导 -->

## 步骤
1. 确认范围（分支 / PR / commit）
2. 收集 git log / diff
3. 按主题用中文输出：动机 → 改动 → 风险 / 测试
4. 若需贴 GitHub，给出可粘贴 Markdown

交互说明（本期 = 向导 + create-skill AI）

  • 入口：Skill 管理器顶栏 / 空态 CTA「生成 Skill」（需 AI 可用）。
  • 前四步：意图 → 触发 description → 落点 → 命名（撞名告警）；不在此步用模板拼正文。
  • AI 草拟：新 agent pane + SlashCommandRequest::InvokeSkill（bundled create-skill）+ 预填 query。
  • 审阅：用户确认写入 / 打开；路径已存在则二次确认覆盖；库存刷新。
  • 非目标：向导内强制 eval UI、自动 commit、改按名合并算法。
