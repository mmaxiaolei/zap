选型备注（给老大）

  • 共同结构：未选中 worktree = 纯文字行；选中 = 至少「左侧竖条 + 高亮」。页签未激活暗色，激活必须有顶/底强调条，可一眼区分。
  • 与北星关系：表面分层 / 圆角 10px / 品牌蓝来自 2026-10-19-zap-shell-northstar-orca-tokens.html。橙 #f5a524 仅作 Orca 对照 token，未写入北星正式色板。
  • 推荐讨论顺序：若优先「品牌统一」→ B 或 C；若优先「Orca 扫描感」→ A；若要「层级语义」→ D。
  • 非目标：本页不改 Rust、不推远程、不改树数据模型；落地时再拆 worktree 父行 vs agent 页签两处样式。
